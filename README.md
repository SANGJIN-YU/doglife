# doglife

**멍BTI** — 내 MBTI와 닮은 견종을 찾고, 그 강아지를 직접 키우는 반려견 육성 게임.

MBTI 16유형을 16개 견종에 1:1로 매칭해 결과를 보여주고, 매칭된 견종의 성향(에너지·독립성·애정도·훈련성)이 그대로 육성 게임의 초기 스탯이 됩니다. 즉 매칭 결과가 곧 "시작 빌드"입니다.

> 견종 매칭은 재미로 보는 콘텐츠이며 과학적 근거를 주장하지 않습니다.

## 현재 상태

온보딩(MBTI 선택 → 견종 매칭 리빌) 화면의 **동작하는 프로토타입**까지 나와 있습니다. 육성 루프는 아직 미구현이며, "이 강아지 키우기 시작" 버튼은 안내 문구만 띄웁니다.

## 프로토타입 실행

의존성이나 빌드 과정이 없습니다. 파일을 브라우저로 바로 열면 됩니다.

```bash
open prototype/mbti-dog-match.html      # macOS
xdg-open prototype/mbti-dog-match.html  # Linux
```

모바일 화면(최대 폭 420px) 기준으로 만들어져 있어, 브라우저 개발자도구의 모바일 뷰에서 보는 편이 실제에 가깝습니다.

## 저장소 구조

```
prototype/mbti-dog-match.html   MBTI-견종 매칭 온보딩 프로토타입 (단일 HTML, 의존성 없음)
docs/game-expansion-spec.md     육성 게임 확장 스펙 — 스코프 평가, 스탯 매핑, 단계별 로드맵
```

## 로드맵

`docs/game-expansion-spec.md`에 전체 내용이 있고, 요약하면 다음과 같습니다.

| 단계 | 내용 | 백엔드 |
|---|---|---|
| **A** | 온보딩 + 코어 케어 루프 (밥·산책·스킨십, 스탯 감소, 성장 단계) | 불필요 (로컬 저장) |
| **B** | 경제 + 수집 (간식 코인, 상점, 코스튬) | Supabase 도입, 재화 로직은 서버 검증 필수 |
| **C** | 소셜 (친구, 방문, 주간 랭킹, 선물) | Supabase Auth + 랭킹 집계 |
| **D** | 라이브옵스 (시즌 이벤트, 신규 아이템 공급) | 상시 운영 리소스 |

Phase A는 서버 없이 착수 가능하고, Phase B부터는 백엔드 설계 확정이 선행되어야 합니다.

## 디자인

프로토타입의 색상·타이포·톤을 이후 단계에서도 그대로 계승합니다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--cream` | `#FFF8EA` | 배경 |
| `--mustard` | `#F3B93A` | 주요 버튼 |
| `--teal` | `#1F4B43` | 인트로 배경, 강조 텍스트 |
| `--coral` | `#FF6F59` | 선택 상태, 특성 게이지 |
| `--ink` | `#2A2620` | 본문 텍스트 |

서체는 제목 Fredoka, 본문 Pretendard입니다.
